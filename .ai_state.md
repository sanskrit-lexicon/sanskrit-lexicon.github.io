## 🧠 Dev Notes & Hypotheses (Bugs, ideas, context)
- The hub (`index.html`), sitemap (`sitemap.xml`/`dictionaries.xml`), and every
  per-dictionary landing page are all generated from the same `DICTS` table via
  `tools/dict-pages/gen_dict_page.py` (`--hub`, `--sitemap`, per-dict modes) — edit the
  table + regenerate, don't hand-edit the generated pages/sitemap directly or they'll
  drift out of sync on the next rollout.
- `tools/dict-pages/` is Jekyll-excluded (`_config.yml: exclude: tools`) so the generator
  scripts don't get published as part of the site.
- Grid CSS uses `minmax(min(100%,260px),1fr)` specifically to avoid overflow on
  ultra-narrow (<300px) viewports (folded phones) — don't revert to a plain `minmax(260px,1fr)`.
